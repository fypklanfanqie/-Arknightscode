Installation

安装说明

1

下载安装器

点击下载按钮，通过夸克网盘获取最新版 .exe 安装包（约 550MB），一键启动安装向导

2

自动配置环境

安装器自动检测并安装 Node.js / Git / Claude Code，无需手动折腾开发环境

3

填入 API Key

在向导中填入 LLM API Key（支持 DeepSeek 等 9 家供应商），测试连接成功后即可与阿米娅对话

⚠️ 需要自备 LLM API Key · Windows 10/11 64 位 · 安装过程需联网下载依赖
