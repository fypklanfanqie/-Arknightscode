## 页面设计

### 整体风格

- 明日方舟罗德岛暗色调
- 底色 `#0a0e17`（罗德岛深蓝黑）
- 主色 `#2eb8ff`（罗德岛蓝）
- 强调色 `#ff8c42`（源石橙）
- 毛玻璃卡片 + 细线边框 + 微弱网格纹理背景

### 页面结构（单页，自上而下）

| # | 板块 | 内容 |
|---|------|------|
| 1 | **Hero** | 大标题 "Arknights code" + 副标题 + tagline + 下载按钮 |
| 2 | **截图预览** | 界面截图展示（网格布局） |
| 3 | **核心特性** | 6 张特性卡片 |
| 4 | **安装说明** | 三步安装流程 |
| 5 | **技术栈** | 技术标签 |
| 6 | **FAQ** | 折叠面板 |
| 7 | **更新日志** | CHANGELOG 链接 |
| 8 | **页脚** | 版权声明 + 微信 `fypkLfq061218` |
